

## تنظيم الملفات والصوت

الواجهة مقسمة إلى `assets/public/index.html` (هيكل الصفحة)، وملفات CSS داخل `assets/public/css/`، و`assets/public/js/app.js` (المنطق). هذه الملفات والأصول مستعادة من الحزمة المرجعية `MANDOURCOFFEE_1.0.82.apk` حتى يطابق مصدر GitHub الواجهة الفعلية للحزمة. يوجد مقطع الصوت الأساسي تحت `assets/audio/`، ويتولى `android-src/MainActivity.java` تشغيله مرة واحدة بعد سداد كل الحسابات. تفاصيل البنية وخطوات التحقق موجودة في [`docs/PROJECT_STRUCTURE.md`](docs/PROJECT_STRUCTURE.md).

## ترتيب الشاشات والتنقل

التنقل الرئيسي له ست شاشات فقط وبالترتيب التالي: الرئيسية، إنشاء فاتورة، العملاء والتوليفات، الشيكات، مركز الإشعارات، ثم المزيد والأدوات. كل شاشة تستخدم رابطًا داخليًا بصيغة `#home` أو `#invoice` أو `#blends` أو `#checks` أو `#notifications` أو `#tools`. عند فتح التطبيق برابط غير معروف يعود تلقائيًا إلى الرئيسية، وعند استخدام زر الرجوع يرجع إلى الشاشة السابقة بدل إعادة تحميل الصفحة.

يُعدَّل مصدر الواجهة داخل `assets/public/` فقط. لا تُضاف مجلدات `www/` أو `android/` إلى المستودع؛ سير العمل في GitHub ينشئهما تلقائيًا أثناء البناء.
