# Mandour Coffee — فواتير وتوليفات البن

تطبيق Android عربي RTL بواجهة فاتحة ثابتة، ألوان قهوة هادئة، رسومات أصلية، وانتقالات ناعمة مع زر رجوع وسجل تنقل يدعم الرجوع في الهاتف. يتيح إنشاء الفواتير بالجرام، حفظ توليفات العملاء، عرض تاريخ آخر فاتورة، وإضافة أنواع بن بصورها وأسعارها.

## الفاتورة والتحضير

- **سادة:** السعر هو سعر البن الأساسي بحسب النوع والوزن.
- **محوّج:** تضاف ١٠ جنيهات لكل ١٢٥ جم (بالحساب التناسبي؛ ٢٥٠ جم = ٢٠ جنيهًا زيادة).
- تعرض الفاتورة سعر البن ورسوم المحوّج والوزن والإجمالي النهائي، وتحفظ نوع التحضير ضمن السجل.

## أصناف البن الأساسية

| الصنف | سعر الكيلو |
| --- | ---: |
| برازيلي سانتوس | ٨٠٠ جنيه |
| كولومبي | ١٠٠٠ جنيه |
| حبشي | ٧٠٠ جنيه |
| إندونيسي | ٧٠٠ جنيه |

بيانات الفواتير والعملاء والأنواع الجديدة تُحفظ محليًا على نفس الجهاز، ولا تنتقل تلقائيًا إلى جهاز آخر.

## إنشاء APK

كل دفع إلى الفرع `main` يشغّل GitHub Actions لبناء APK مع صور الأصناف ورسمة الواجهة. يمكن أيضًا تشغيل **Actions → Build APK → Run workflow** يدويًا؛ نزّل `mandour-coffee.apk` من أحدث إصدار في **Releases**.

الملف الناتج Debug APK للتجربة والتثبيت المباشر، وليس نسخة موقعة للنشر على Google Play.
