# Mandour Coffee — تطبيق البن

تطبيق عربي RTL بُني من ألوان وفئات CSS التي أرسلها المستخدم. يتضمن شاشة ترحيب، مظهرًا داكنًا وفاتحًا، اختيار نوع البن ووزنه بالجرام، تقدير السعر، وسلة طلب محلية.

## إنشاء APK

عند الدفع إلى `main`، أو تشغيل **Actions → Build APK → Run workflow** يدويًا، يبني GitHub Actions تطبيق Android بصيغة APK وينشره في **Releases**. ابحث عن `mandour-coffee.apk` في أحدث إصدار.

الملف الناتج Debug APK للتجربة والتثبيت المباشر، وليس نسخة موقعة للنشر على Google Play. الأسعار داخل التطبيق تقديرية ويجب تأكيدها عند الطلب.
