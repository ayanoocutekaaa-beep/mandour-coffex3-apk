# Mandour Coffee — فواتير وتوليفات البن

تطبيق Android عربي لإدارة فواتير القهوة وتوليفات العملاء. الواجهة محدّثة بألوان دافئة، أيقونات موحّدة، تنقل سفلي سريع، انتقالات هادئة، وملخص ثابت يظهر أثناء إعداد الفاتورة. زر الرجوع السفلي في الهاتف يعيد الشاشة السابقة داخل التطبيق قبل إغلاقه.

## الوظائف

- إنشاء فاتورة بإدخال الوزن بالجرام وحساب سعر كل نوع بن تلقائيًا.
- الاختيار بين **سادة** بالسعر الأساسي، أو **محوّج** مع إضافة ١٠ جنيهات لكل ١٢٥ جم؛ أي ٢٠ جنيهًا لكل ٢٥٠ جم.
- حفظ الفواتير محليًا مع اسم العميل والتفاصيل والإجمالي، وطي سجل الفواتير لتقليل ازدحام الشاشة.
- حفظ توليفات للعملاء وإظهار آخر فاتورة مسجلة بالاسم.
- إضافة أنواع بن جديدة بالاسم والسعر وصورة من الجهاز.

الفواتير والعملاء والأصناف المضافة تُحفظ محليًا على الهاتف. النسخة v5 تستخدم معرّف تطبيق مستقلًا (`com.mandour.coffee.v5`) كي تبقى نسخة v4 القديمة وبياناتها دون تغيير؛ تبدأ v5 ببياناتها المحلية الجديدة.

## البناء والتنزيل

أي دفع إلى `main` يشغّل GitHub Actions لبناء APK تجريبي وإرفاقه في إصدار GitHub جديد. يتضمن البناء أيقونة Mandour الجديدة ومعالج زر الرجوع الأصلي لـ Android. يمكن تنزيل `mandour-coffee-v5.apk` من صفحة **Releases** بعد نجاح البناء.

الـAPK الناتج للتجربة والتثبيت المباشر، وليس حزمة موقعة للنشر على Google Play.
