# مندوركوف

تطبيق عربي لإدارة فواتير البن، العملاء والتوليفات، طلبات الكافيه والشيكات والمدفوعات. يدعم حفظ البيانات محليًا، الإشعارات، التقارير، والنسخ الاحتياطي والاستعادة.

الواجهة الافتراضية بالوضع الداكن المستوحى من ألوان القهوة، مع إمكانية اختيار الوضع الفاتح من إعدادات التطبيق.

## مصادر التطبيق المعتمدة

- `assets/public/index.html`: هيكل الشاشات وتسميات الأزرار والتنقل.
- `assets/public/css/tokens.css`: ألوان ومسافات التصميم المشتركة.
- `assets/public/css/app.css`: تنسيقات المكونات والشاشات الأساسية.
- `assets/public/css/cashier.css`: تدفق الطلبات والطاولات وتنسيقات الهاتف.
- `assets/public/css/dark-theme.css`: طبقة الوضع الداكن المستقلّة.
- `assets/public/js/app.js`: منطق الفواتير والعملاء والشيكات والتنبيهات والتخزين المحلي.
- `assets/mandour-app-icon.png`: الصورة المعتمدة لشعار التطبيق وأيقونة الويب.
- `assets/mandour-app-icon-foreground.png`: مصدر الصورة المعتمدة لتوليد طبقة Adaptive Icon.
- `android-res/mipmap-*`: أيقونات Android وأحجامها المختلفة.
- `android-res/mipmap-anydpi-v26/`: تعريف Adaptive Icon على Android الحديث.
- `android-res/values/ic_launcher_background.xml`: لون خلفية Adaptive Icon.
- `android-src/MainActivity.java`: جسر Android للنسخ الاحتياطي ومشاركة الإيصالات وتشغيل الصوت.
- `assets/audio/`: أصوات التنبيهات والتفاعل.
- `.github/workflows/build.yml`: بناء Android ونشر APK عند تحديث الفرع الرئيسي.

> عدّل ملفات المصدر أعلاه؛ لا تعدّل `www/` أو `android/` الناتجين عن Capacitor. المصدر الأساسي هو `assets/public/index.html`؛ تتم مزامنة `index.html` في جذر المستودع معه لعرض المعاينة نفسها.

## التحقق والبناء

```bash
node --check assets/public/js/app.js
git diff --check
```

تتم مزامنة واجهة الويب إلى Android عبر `npx cap sync android`، ثم إنشاء APK عبر `./gradlew assembleDebug` من مجلد Android.

## البنية

```text
assets/
  public/          واجهة التطبيق: HTML وCSS وJavaScript
  audio/           الأصوات
  beans/           صور أنواع البن
  menu/            صور المشروبات
  payments/        صور وشعارات الدفع
android-res/       أيقونات وموارد Android المصدرية
android-src/       كود Java الخاص بالتكامل مع Android
docs/              توثيق بنية المشروع وآليات النسخ الاحتياطي
.github/workflows/ مسار بناء APK
```

تسجل الشيكات أحداث الطلبات والخصومات والمدفوعات؛ حافظ على فصل المبلغ الإجمالي والمدفوع والمتبقي، وعلى بيانات الطاولة/التيك أواي والعملاء. المسودة الحالية محفوظة في `data.pendingOrder` حتى اعتماد الأصناف، مع تأكيد صريح قبل نقلها إلى حساب مختلف.


## الطاولات وحماية الطلب الحالي

تدفق الكاشير يستخدم شريطًا موحدًا للطاولات ١–٥، ويعرض الحسابات النشطة على الطاولة مباشرة. تحفظ أصناف الطلب ووجهته في `data.pendingOrder` محليًا، وتُستعاد بعد الانتقال بين الشاشات أو إعادة فتح التطبيق. تغيير الوجهة مع وجود أصناف يتطلب تأكيدًا صريحًا؛ وفشل حفظ الحساب لا يمسح المسودة. رصيف التأكيد موضوع خارج أقسام الشاشات المتحركة ليظل ثابتًا فوق التنقل السفلي، ويختفي عند الكتابة لتفادي لوحة مفاتيح الهاتف.

استيراد النسخة يدمج مجموعات التطبيق بدل تجاهل بعضها. إذا كانت هناك مسودة محلية تحتوي أصنافًا، تُحفظ كما هي لتجنب استبدال طلب جارٍ؛ وإن لم توجد أصناف محلية، يمكن استعادة مسودة النسخة المستوردة. حفظ `Ayanoo.json` في Android يكتب نسخة مؤقتة ويتحقق منها قبل استبدال الملف السابق، مع إبقاء السابقة عند فشل التحديث.
