# Mandour Coffee — فواتير وتوليفات البن

تطبيق Android عربي RTL بواجهة فاتحة دائمة وشاشة ترحيب متحركة. يتيح إنشاء الفواتير بحساب تلقائي من وزن البن بالجرام، حفظ توليفات العملاء، إظهار وقت آخر فاتورة باسم العميل، وإضافة أنواع بن بصورها وأسعارها.

## أصناف البن الأساسية

| الصنف | سعر الكيلو |
| --- | ---: |
| برازيلي سانتوس | ٨٠٠ جنيه |
| كولومبي | ١٠٠٠ جنيه |
| حبشي | ٧٠٠ جنيه |
| إندونيسي | ٧٠٠ جنيه |

بيانات الفواتير والعملاء والأنواع الجديدة تُحفظ محليًا على نفس الجهاز، ولا تنتقل تلقائيًا إلى جهاز آخر.

## إنشاء APK

كل دفع إلى الفرع `main` يشغّل GitHub Actions لبناء APK مع صور الأصناف. كما يمكن تشغيل **Actions → Build APK → Run workflow** يدويًا. نزّل `mandour-coffee.apk` من أحدث إصدار في **Releases**.

الملف الناتج Debug APK للتجربة والتثبيت المباشر، وليس نسخة موقعة للنشر على Google Play.
