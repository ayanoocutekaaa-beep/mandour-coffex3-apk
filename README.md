# Mandour Coffee

صفحة منيو عربية لمقهى مندور، مع صور المشروع داخل مجلد `assets/`.

## بناء تطبيق Android

عند الدفع إلى الفرع `main`، أو تشغيل سير العمل يدويًا من تبويب **Actions**، ينشئ GitHub Actions تطبيق Android بصيغة APK وينشره كإصدار في **Releases**. ابحث عن الملف `mandour-coffee.apk` في أحدث إصدار.

ملف APK الناتج نسخة **Debug** للتجربة والتثبيت المباشر، وليس إصدارًا موقّعًا للنشر على Google Play.
