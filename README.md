# Mandour Coffee — فواتير وتوليفات البن

تطبيق Android عربي لإدارة مبيعات البن، التوليفات، والإيصالات. الواجهة دافئة وبسيطة، مع انتقال سفلي وملخص ثابت للفواتير.

## الفواتير والإيصالات

- يحفظ كل مستند بتاريخ الشراء الذي تختاره (والافتراضي هو تاريخ اليوم)، مع تاريخ صلاحية اختياري.
- يعرض آخر ٣٠ يومًا مجمعة يومًا بيوم، ويحفظ الأقدم في أرشيف شهري قابل للبحث؛ لا يحذف الأرشيف تلقائيًا.
- يدعم **إيصال بيع** و**عرض سعر**، ويبقي سعر التحضير الحالي كما هو: سادة أو محوّج. تضاف ١٠ جنيهات لكل ١٢٥ جم للمحوّج.
- افتح أي مستند لرؤية صورة إيصال بطابع قهوة، فيها رقم المستند والعميل والتواريخ وأنواع البن والأوزان والأسعار والإجمالي.
- شارك صورة الإيصال من قائمة Android للتطبيقات المتوافقة، أو نزّلها/اطبعها. يتاح WhatsApp وInstagram وTikTok بحسب دعم التطبيق المثبّت للمشاركة بالصور.
- إعادة إصدار فاتورة عميل تنسخ الأصناف والأوزان والتحضير، وتضبط تاريخ شراء جديدًا وتترك تاريخ الصلاحية لتحديثه.
- حذف الفاتورة لا يتم إلا بعد تأكيدين منفصلين.

## إدارة البيانات

- كل الفواتير والتوليفات والعملاء والأصناف الإضافية محفوظة محليًا على الهاتف؛ لا تزامن تلقائيًا مع جهاز آخر.
- الفواتير القديمة قبل إضافة التواريخ تظل ظاهرة باستخدام تاريخ الحفظ الموجود لديها.
- الإصدارات الأحدث تستخدم معرّف Android نفسه لنسخة v5 (`com.mandour.coffee.v5`) لتُثبّت كتحديث وتحافظ على بيانات v5. وتظل v4 مستقلة بمعرّفها وبياناتها.

## البناء

كل دفع إلى `main` يشغّل GitHub Actions ويبني APK تجريبيًا وينشئ Release جديدًا. الملف للتجربة والتثبيت المباشر، وليس إصدارًا موقعًا للنشر على Google Play.
